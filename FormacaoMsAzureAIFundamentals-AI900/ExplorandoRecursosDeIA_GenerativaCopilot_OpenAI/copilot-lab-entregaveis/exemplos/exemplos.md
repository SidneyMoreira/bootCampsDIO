# Exemplos de Uso do Copilot

## Exemplo 1 – Função de Soma em Python
```python
def soma(a, b):
    return a + b
```

## Exemplo 2 – Geração de Teste Unitário
```python
import unittest

class TestSoma(unittest.TestCase):
    def test_soma(self):
        self.assertEqual(soma(2, 3), 5)
```

Esses trechos foram sugeridos automaticamente pelo Copilot a partir de descrições simples.
