# Copiloto de Vendas IA — Loja Gamer

## Descrição

Este README apresenta o uso do `Copiloto de Vendas IA — Loja Gamer`, um prompt criado para gerar um assistente de vendas especializado em loja gamer. O objetivo é transformar o prompt em um copiloto comercial capaz de ajudar vendedores e consultores a conduzir atendimentos mais eficientes, identificar oportunidades, sugerir ofertas e seguir o cliente até a venda.

## Finalidade

O `Copiloto de Vendas IA — Loja Gamer` foi desenvolvido como desafio do Bootcamp DIO em parceria com a Lupo. Ele serve para:

- Interpretar o interesse do cliente em produtos gamer
- Classificar perfil, urgência e nível técnico do lead
- Definir tom de abordagem e gatilhos de decisão
- Sugerir ofertas principais, complementos e estratégias de ancoragem
- Antecipar objeções e sinais de fechamento
- Criar mensagens prontas para WhatsApp e follow-up

## Para quem é indicado

Este prompt é útil para:

- Vendedores de lojas de produtos gamer
- Consultores de atendimento digital
- Representantes de e-commerce e redes sociais
- Equipes de vendas que usam IA para melhorar conversas com clientes

## Como usar

1. Abra o arquivo `Copiloto de Vendas IA — Loja Gamer` no seu editor ou na ferramenta de IA.
2. Use o prompt como sistema/instrução inicial do modelo.
3. Envie o interesse do cliente como entrada.
4. Acrescente sempre que possível detalhes como orçamento, jogos, uso, urgência e preferência entre PC ou notebook.
5. Peça ao modelo para responder seguindo a estrutura definida no prompt.

### Exemplo de input

```text
"Cliente quer um notebook para faculdade e jogar, com orçamento de até 5 mil e urgência de compra neste mês."
```

### Resposta esperada do assistente

O modelo deve gerar um atendimento completo com as seções abaixo, sempre nesta ordem:

- Leitura do interesse
- Perfil do cliente
- Quem decide a compra
- Nível de urgência do lead
- Nível de conhecimento técnico do cliente
- Tom ideal da abordagem
- Gatilho principal de decisão
- Diagnóstico de oportunidade
- Perguntas de qualificação
- Oferta principal recomendada
- Melhor argumento de venda
- Oferta complementar inteligente
- Estratégia de ancoragem
- Comparação rápida (quando relevante)
- Possíveis objeções e como responder
- Medo oculto do cliente
- Sinais de fechamento
- Risco de perda da venda
- Próxima melhor ação
- Mensagem pronta para WhatsApp
- Mensagem de fechamento
- Follow-up automático

## Dicas de uso eficiente

- Seja claro e completo no input: quanto mais dados, melhor será a análise.
- Se o cliente não disser orçamento, use hipóteses cautelosas em vez de inventar valores.
- Mantenha as perguntas de qualificação curtas e objetivas.
- Utilize os campos de oferta complementar apenas quando fizer sentido real.
- Use as mensagens prontas e follow-ups para acelerar o atendimento no WhatsApp.

## Estrutura do prompt

O `Copiloto de Vendas IA — Loja Gamer` define:

- papel e objetivo do assistente
- contexto de negócio com produtos high ticket e low ticket
- formato de input desejado
- estrutura obrigatória de resposta com 22 sessões

## Exemplo de cenário de uso

1. O vendedor recebe a mensagem do cliente.
2. Ele fornece o interesse e os detalhes ao modelo.
3. O modelo devolve a análise e as recomendações.
4. O vendedor usa a mensagem pronta ou follow-up para continuar o atendimento.
5. O processo repete até o fechamento.

## Observação

O prompt foi criado para funcionar como um guia completo de vendas e não como uma solução única para qualquer cliente. Ajustes adicionais podem ser necessários para o estilo da loja, política de preços e mix de produtos.
