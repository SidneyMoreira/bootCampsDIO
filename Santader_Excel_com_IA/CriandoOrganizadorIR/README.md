# 📊 LION IR – Agregador de Dados para Imposto de Renda (Excel)

## 📌 Entendendo o Desafio

Este projeto faz parte de um desafio prático da **DIO**, cujo objetivo é consolidar os conhecimentos adquiridos ao longo das aulas por meio da **documentação de uma solução prática desenvolvida em Excel**.

O foco do desafio é demonstrar, de forma clara e organizada, o funcionamento de uma planilha criada para **organização e controle de informações essenciais à declaração do Imposto de Renda Pessoa Física (IRPF)**.

---

## 🧾 Descrição do Projeto

A planilha **LION IR** é um **agregador de dados para imposto de renda**, totalmente construída em Excel, que permite ao usuário registrar e centralizar informações relevantes da declaração anual, utilizando:

- Interface visual organizada  
- Menu lateral para navegação  
- Botões de avanço e retorno entre telas  
- Validações automáticas de campos  
- Estrutura lógica dividida por etapas  

Toda a navegação é feita **exclusivamente por meio do menu e dos botões**, não sendo necessário trocar abas manualmente.

---

## 🧭 Estrutura e Navegação da Planilha

A planilha é organizada em **três seções principais**, acessíveis pelo menu lateral:

- **TITULAR**
- **INFORMES**
- **NOTAS**

Cada seção representa uma etapa do preenchimento e pode ser acessada:
- Pelo **menu lateral**
- Pelos botões **“PRÓXIMO →”** e **“← ANTERIOR”**

---

## 🧑‍💼 1. Titular – Dados do Declarante

Nesta seção são informados os **dados cadastrais do titular da declaração**, incluindo:

- Nome completo  
- CPF  
- Data de nascimento  
- Título de eleitor  
- Estado civil  
- Endereço completo  
- CEP  
- Telefones e e-mail  
- Informações complementares relevantes ao IR  

Os campos apresentados seguem um padrão visual que indica claramente onde o usuário deve inserir as informações.  
As respostas de **SIM / NÃO** utilizam seleção controlada, garantindo consistência dos dados.

---

## 🏦 2. Informes – Rendimentos Bancários

Nesta etapa, o usuário registra os **informes de rendimentos bancários**, organizados por instituição financeira.

Para cada banco, são apresentados campos para:
- Seleção da instituição financeira  
- Valor atual informado  
- Anexo do comprovante (exemplo: PDF do informe)  

A tela exibe:
- Registros individuais por banco  
- **Total geral automático**, consolidando todos os valores informados  

Essa seção centraliza os dados bancários necessários para a declaração anual.

---

## 📒 3. Notas – Extrato de Entradas / Holerites

A seção **NOTAS** é destinada ao registro das **entradas mensais de receita**, como holerites ou outros rendimentos recorrentes.

A tabela apresenta as colunas:
- **Data (mês/ano)**  
- **Categoria**  
- **Valor**  

Os registros são feitos de forma contínua, permitindo o controle histórico das entradas financeiras ao longo do ano-base da declaração.

## 📌 Considerações Finais

A planilha **LION IR** representa uma solução prática e organizada para apoio à declaração de imposto de renda, reunindo informações do titular, informes bancários e registros de entradas financeiras em um único ambiente.
